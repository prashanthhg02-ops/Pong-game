# 🏓 Pong Game

A simple and interactive **Pong Game** developed as a game development project. The game is inspired by the classic Pong arcade game, where players control paddles to hit the ball and score points.

## 🎮 Features

- Classic Pong gameplay
- Two-player support
- Keyboard controls
- Ball movement and collision detection
- Score tracking
- Simple and user-friendly interface
- Game over / winning condition
- Restart and replay functionality

## 🕹️ Controls

### Player 1
- `W` → Move paddle up
- `S` → Move paddle down

### Player 2
- `↑` → Move paddle up
- `↓` → Move paddle down

### General
- `Space` → Start / Restart the game
- `Esc` → Exit the game (if supported)

## 🎯 Objective

The main objective of the game is to hit the ball using your paddle and prevent it from passing your side.

The player who reaches the required score first wins the game.
